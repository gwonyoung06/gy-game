# 헌터즈 (HUNTERS) 게임 기획서

> 제출 기한: 2025년 5월 26일

---

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 게임명 | 헌터즈 (HUNTERS) |
| 장르 | 3D 캐주얼 헌팅 액션 |
| 플랫폼 | 웹 브라우저 (PC / 모바일) |
| 시점 | 3인칭 (1인칭 전환 가능) |
| 플레이어 수 | 1인 (글로벌 리더보드 경쟁) |
| 대상층 | 남녀 모두, 전 연령 |
| 핵심 컨셉 | 잠자리채부터 전자기 포획기까지 — 곤충에서 UFO까지 사냥하는 캐주얼 헌팅 게임 |

---

## 2. 핵심 규칙

1. 각 스테이지마다 **제한 시간** 내에 **목표 마리수 이상** 포획해야 클리어
2. 포획할 때마다 **코인 획득** (빠르게 잡을수록 보너스)
3. 코인으로 **상점에서 도구·능력·펫·스킬** 구매
4. 같은 스테이지 **반복 플레이**로 파밍 가능 (반복 시 코인 80% 지급)
5. 특정 도구 없이는 다음 단계 진입 불가 (게이트키핑)

---

## 3. 플레이 방식

### 기본 조작
```
WASD / 방향키  → 이동
마우스 이동    → 시점 조작
좌클릭         → 도구 사용 (채망 휘두르기 / 포획 시도)
E              → 특수 스킬 사용
Tab            → 상점 열기
F              → 1인칭 ↔ 3인칭 전환
```

### 스테이지 진행 구조
```
스테이지 선택
    ↓
난이도 선택 (Easy / Normal / Hard / Extreme)
    ↓
환경 설정 (날씨 / 시간대 / 맵 크기)
    ↓
웨이브 1 → 웨이브 2 → 웨이브 3
    ↓
(5·10단계) 미니 보스 웨이브
    ↓
결과 화면 (점수 / 코인 / 랭킹 등록)
    ↓
상점 or 다음 스테이지
```

## 5. 핵심 시스템

### 코인 경제

| 단계 구간 | 마리당 기본 코인 | 빠른 포획 보너스 |
|----------|---------------|---------------|
| 1~3단계 | 10~30 | +5 |
| 4~6단계 | 50~100 | +20 |
| 7~9단계 | 150~300 | +50 |
| 10~12단계 | 400~800 | +150 |
| 13~14단계 | 1,000~3,000 | +500 |
| 15단계 UFO | 10,000 | +2,000 |

### 점수 계산식
```
스테이지 점수 = (포획 마리수 × 마리당 점수)
             + (남은 시간 × 10)
             + (콤보 보너스)
             × 난이도 배율
```

### 콤보 시스템
- 3마리 연속 포획 → 1.2x
- 5마리 연속 포획 → 1.5x
- 10마리 연속 포획 → 2.0x 🔥

### 난이도 설정

| 난이도 | 시간제한 | 목표 마리수 | 생물 속도 | 코인 배율 |
|--------|---------|------------|---------|---------|
| 🟢 Easy | +30초 | -30% | 느림 | 0.7x |
| 🟡 Normal | 기본 | 기본 | 기본 | 1.0x |
| 🔴 Hard | -20초 | +30% | 빠름 | 1.5x |
| 💀 Extreme | -40초 | +60% | 매우 빠름 | 2.5x |

### 환경 설정

| 옵션 | 선택지 | 효과 |
|------|--------|------|
| 날씨 | ☀️맑음 / 🌧️비 / 🌫️안개 | 비=생물 느림+20% / 안개=시야 감소+50% |
| 시간대 | 🌅낮 / 🌇노을 / 🌙밤 | 밤=야행성 생물+40% |
| 맵 크기 | 기본 / 확장 / 광역 | 확장=생물 2배 / 광역=3배 |

## 8. 화면 구성

### 주요 화면 목록
1. **타이틀 화면** — 게임 로고, 시작/설정/랭킹 버튼
2. **스테이지 선택 화면** — 15개 스테이지 맵, 잠금/해금 표시
3. **스테이지 설정 화면** — 난이도, 날씨, 시간대, 맵 크기 선택
4. **인게임 HUD** — 타이머, 목표 마리수, 현재 포획수, 코인, 콤보
5. **상점 화면** — 탭별 (도구/능력/커스텀/펫/스킬) 구매
6. **결과 화면** — 점수, 획득 코인, 랭킹 등록
7. **리더보드 화면** — 글로벌/개인 기록

## 9. 주요 재미 요소

1. **성장 쾌감** — 잠자리채 → 전자기 포획기로 도구가 진화하는 성장감
2. **서프라이즈** — 곤충→수중→공룡→UFO로 예측 불가한 스테이지 전환
3. **빌드 전략** — 펫·스킬·업그레이드 조합으로 자신만의 플레이 스타일
4. **경쟁심** — 글로벌 리더보드로 친구·전 세계와 점수 경쟁
5. **꾸미기** — 의상·도구 스킨 수집의 수집 욕구 자극

## 10. 차별화 포인트

- **장르 참신성** — "UFO를 잠자리채로 잡는다"는 설정 자체가 화제성
- **비폭력적 콘텐츠** — 잡아서 포획하는 방식으로 전연령 친화적
- **남녀 모두 어필** — 귀여운 비주얼 + 전략적 빌드 + 꾸미기 요소 복합
- **무한 재플레이** — 난이도·환경·빌드 조합으로 540+ 가지 플레이 경우의 수
